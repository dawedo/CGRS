# CGRS
Group recommender systems are critical in discovering relevant items from a near-infinite inventory by  considering collective preferences rather than individual one. we propose a conformal prediction framework that provides a measure of  confidence with prediction in conjunction with a GRS to augment the system-generated  plain recommendations.
